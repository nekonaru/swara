# Changelog

## v3.3.0

Performance release: the app now renders lists and artwork like a native player, and the project follows one shared release process.

## New features

- **Native-smooth lists and artwork.** Library, search and dashboard lists now decode artwork at display size, skip per-frame layout work, and repaint only what changed, so scrolling stays fluid on large libraries.

## Improvements

- **Release body comes from this file.** The draft release generated by the build workflow now lists this changelog instead of hardcoded notes, and the release title is `Swara vX.Y.Z`.
- **Android project committed.** The `android/` folder is now part of the repository instead of being regenerated and patched by CI on every build, so builds are reproducible and the workflows are shorter.

## Bug fixes

- **Wrong author avatar in the README.** The Author section now links the real author avatar and profile.

## v3.2.0

One shared theme and artwork that flies into the player.

## New features

- **One design system for the whole app.** A new `lib/theme/app_theme.dart` defines the app bar, cards, dialogs, list rows, buttons, snackbars, tabs, dividers, bottom sheets and page transitions in one place. Light and dark are both built by the same function, so the two can no longer drift apart.
- **Artwork flies into the player.** Tapping the mini player grows its small cover into the big cover on the player screen, instead of swapping two unrelated pictures.
- **One page transition everywhere.** Screens open with a short fade and a small upward slide rather than the default zoom, and the player keeps its own motion from the bottom.

## Improvements

- **Muted text follows the theme.** Seventy hardcoded grey text and icon colors across fifteen files now use the theme's secondary color, so they adapt to light, dark and AMOLED backgrounds and to the accent color you pick.
- **Snackbars float by default.** They no longer hug the bottom edge just because a screen forgot to ask for floating behavior.
- **Library tabs match the rest of the app.** Selected and unselected labels, and the hairline under the bar, now come from the theme instead of Material defaults.
- **Progress bars follow your accent.** The loading track used to stay the default purple when your accent was teal or orange; it now uses your theme.

## Bug fixes

- **Three different greys for the same kind of text are gone.** A subtitle could be readable on one screen and nearly invisible on the next, especially on the AMOLED black background; they now all use one themed color.
- **Dialogs, sheets and rows keep one shape.** Hand-styled corners per screen meant the same kind of popup looked different depending on where it opened.

## v3.1.0

Manual-only metadata scans, and every scan is stoppable.

## New features

- **Manual-only metadata scans.** Metadata scans no longer start on their own, and every scan can be stopped halfway with nothing lost.

## v3.0.0

Security hardening release.

## Improvements

- **adb backup disabled.** The app's local database, favorites and listening history can no longer be pulled off the phone with `adb backup`.
- **Dependencies updated.** All dependencies were moved to current compatible versions.

## Earlier releases

v2.9.x and below are listed on the GitHub Releases page. Highlights from that line: full lists without a Load more button, instant A-Z jump, typo-tolerant search with a "did you mean" hint, off-main-thread search and scanning, hoisted regexes and cached derived views, one lrclib request for plain and synced lyrics, quick settings shortcut fix, and a crash fix for songs with an empty file path.
